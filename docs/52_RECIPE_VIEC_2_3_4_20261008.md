### 3.1 Thay cột «Thao tác» (c9) — `WorkCenter.tsx:443-446`

```tsx
</div></> }
```

**Mới** — thêm **component ở CẤP MODULE** (theo đúng bài học U-13 ở `WorkCenter.tsx:438-441`: ⛔ không khai báo component trong thân render):
```tsx
// USER 08/10/2026 — VIỆC 3: ⛔ bỏ 4 nút preset 25/50/75/100% ⇒ cho user NHẬP % hoàn thành.
// ⭐ ĐỒNG THỜI SỬA BUG §1.2: nút «Xong» cũ gửi `COMPLETED` (BE CHẶN người thực hiện —
//    `OpsTaskManagementUseCase:369-370`) ⇒ nay: người thực hiện gửi `SUBMITTED` («Gửi kiểm tra»),
//    chỉ TRƯỞNG PHÒNG/admin mới gửi `COMPLETED` («Duyệt xong»).
function ProgressCell({ row, busy, send, canApprove }: { row: Row; busy: boolean; send: (name: string, payload: Row) => Promise<void>; canApprove: boolean }) {
  const [value, setValue] = useState(String(Number(row.progress || 0)));
  useEffect(() => { setValue(String(Number(row.progress || 0))); }, [row.progress]);
  const current = Number(row.progress || 0);
  const dirty = Math.max(0, Math.min(100, Math.round(Number(value) || 0))) !== current;
  return <div className="row-actions" data-vntech="work-progress-cell">
    <input type="number" min={0} max={100} step={5} value={value} disabled={busy}
      aria-label={`Phần trăm hoàn thành ${String(row.taskNo || "")}`} style={{ width: "5.5rem" }}
      onChange={(event) => setValue(event.target.value)} />
    <span aria-hidden="true">%</span>
    <button type="button" className="export-mini" disabled={busy || !dirty}
      onClick={() => void send("update_work_item_progress", { workItemId: row.id, progress: Math.max(0, Math.min(100, Math.round(Number(value) || 0))) })}>Lưu</button>
    {canApprove
      ? String(row.status) !== "COMPLETED" && <button type="button" className="export-mini" disabled={busy}
          onClick={() => void send("update_work_item_status", { workItemId: row.id, status: "COMPLETED" })}>Duyệt xong</button>
      : ["NEW", "IN_PROGRESS", "REWORK"].includes(String(row.status)) && <button type="button" className="export-mini" disabled={busy}
          onClick={() => void send("update_work_item_status", { workItemId: row.id, status: "SUBMITTED" })}>Gửi kiểm tra</button>}
  </div>;
}
```
**Cột mới**: `{ key: "c9", header: "Tiến độ & xác nhận", render: (r) => <ProgressCell row={r} busy={busy} send={send} canApprove={canApproveRow(r)}/> }` — và truyền thêm prop cho `TaskTable`:

**Nguồn `canApproveRow`** (đối chiếu đúng luật BE `store.userIsDepartmentManager`): dùng `workScopeOf(data)` đã có trong tệp:
